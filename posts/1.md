# 我的第一篇 React 心得

這是我的第一篇 React 學習筆記。今天終於學會了 **React Router** 的基本用法，感覺單頁面應用程式 (SPA) 的體驗真的很棒！

---

## 為什麼選擇 React？

在學習 React 之前，我主要是使用原生 JavaScript (Vanilla JS) 來操控 DOM。當專案變大時，程式碼會變得非常難以維護。React 帶來了全新的思維：

* **組件化開發 (Component-Based)**：把 UI 拆分成獨立、可重用的積木。
* **聲明式渲染 (Declarative)**：我們只需關注「畫面應該呈現什麼狀態」，而不是「如何去修改 DOM」。
* **強大的生態系**：例如 React Router、Framer Motion 等，讓開發單頁應用與動畫變得非常簡單。

---

## React Router 的核心概念

在 SPA 中，我們不需要重新整理網頁就能切換內容。以下是我今天學到的幾個核心組件：

1. `<BrowserRouter>`：提供路由的上下文環境。
2. `<Routes>`：包裝所有的路由規則，負責匹配當前網址。
3. `<Route>`：定義路徑 (`path`) 與對應渲染的組件 (`element`)。
4. `<Link>`：用來導覽的超連結，避免觸發瀏覽器的預設重新整理行為。

```jsx
import { BrowserRouter as Router, Routes, Route, Link } from 'react-router-dom';

function App() {
  return (
    <Router>
      <nav>
        <Link to="/">首頁</Link>
        <Link to="/about">關於我</Link>
      </nav>
      
      <Routes>
        <Route path="/" element={<Home />} />
        <Route path="/about" element={<About />} />
      </Routes>
    </Router>
  );
}
```
