# CSS Flexbox 懶人包

靠右、靠左、垂直置中？這篇讓你一次搞懂 Flexbox 的核心邏輯，再也不用猜屬性！

---

## 什麼是 Flexbox？

**Flexbox (Flexible Box Layout)** 是一種一維的排版模型，用來處理同一行或同一列中元件的對齊、分配空間與順序。

要啟用 Flexbox，只需在父容器設定：

```css
.container {
  display: flex;
}
```

---

## 核心概念：雙軸線 (Main Axis & Cross Axis)

Flexbox 的所有屬性都是圍繞著這兩條軸線運作的：
1. **主軸 (Main Axis)**：預設是水平方向（從左到右）。
2. **交叉軸 (Cross Axis)**：垂直於主軸的方向，預設是垂直方向（從上到下）。

---

## 常見的父容器屬性

### 1. `flex-direction`（決定主軸方向）
* `row` (預設值)：水平從左到右。
* `column`：垂直從上到下。

### 2. `justify-content`（決定元件在主軸上的對齊方式）
* `flex-start` (預設)：靠主軸起點對齊。
* `flex-end`：靠主軸終點對齊。
* `center`：置中對齊。
* `space-between`：平均分配，首尾緊貼容器邊緣。
* `space-around`：平均分配，每個元件兩側留有相同間距。

### 3. `align-items`（決定元件在交叉軸上的對齊方式）
* `stretch` (預設值)：拉伸填滿整個交叉軸高度。
* `center`：垂直置中。
* `flex-start`：靠交叉軸起點對齊。
* `flex-end`：靠交叉軸終點對齊。

---

## 最常用的「終極置中」大法

如果你想讓一個子元件在父容器中完美置中，只需要這三行程式碼：

```css
.parent {
  display: flex;
  justify-content: center; /* 水平置中 */
  align-items: center;     /* 垂直置中 */
}
```

## 總結

理解 Flexbox 的關鍵在於**分清主軸和交叉軸**。當你設定 `flex-direction: column` 時，`justify-content` 控制的就會變成垂直方向，而 `align-items` 控制的則是水平方向。

多練習幾次，你就能徹底掌握 Flexbox！
